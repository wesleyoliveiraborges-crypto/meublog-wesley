# Página Web: do Zero à Primeira Interação

## Objetivo

Este projeto apresenta a criação de uma página web simples utilizando:

- HTML
- CSS
- JavaScript

O usuário pode clicar em um botão e visualizar uma mensagem dinâmica, demonstrando a primeira interação com JavaScript.

---

## Tecnologias

- HTML5
- CSS3
- JavaScript

---

## Estrutura

```
pagina-web-primeira-interacao/
│
├── index.html
├── styles.css
├── script.js
└── README.md
```

---

## Como executar

1. Baixe o projeto.
2. Abra a pasta.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar nenhuma dependência.

---

## Funcionalidades

- Página responsiva
- Estilização com CSS
- Evento de clique
- Alteração dinâmica do conteúdo
- Manipulação do DOM

---

## Aprendizados

Durante este projeto é possível aprender:

- Estrutura HTML
- Seletores CSS
- Eventos JavaScript
- Manipulação do DOM
- Organização de projetos web
